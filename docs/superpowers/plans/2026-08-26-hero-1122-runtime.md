# Hero 1122 runtime implementation plan

**Goal:** Make local hero 1122 (Lexa, sourced from official client hero 1123) consume its configured combat effects instead of leaving them inert.

**Source of truth:** `hero_skill.xml`, `effectid.xml`, the decoded official client description `HeroSkillDesWithValue112301`, and the existing 1106/1120 server implementations.

## Scope

1. Add pure, unit-testable rules for rally qualification, air-supremacy scaling, caps, five-round synergy layers, and the one-shot wind-field window.
2. Add `Skill1122` for skill IDs 112201-112205 and proficiency effect 12981.
3. Add effect checkers for documented effects 12961-12967 and 12970, proficiency effect 12981, and soul effects 12991-12993; consume duration effect 12994 in `Skill1122`.
4. Keep 12968/12969 inert: the client table names them, but the full skill description has no trigger or placeholder for either value.
5. Integrate the dynamic round-dependent modifiers into battle attack, super attack, outgoing damage, incoming damage, and bomber dodge calculation.
6. Run focused tests, compile the server, then perform an adversarial review for cross-player leakage, integer division, phantom units, caps, timing, and double application.
